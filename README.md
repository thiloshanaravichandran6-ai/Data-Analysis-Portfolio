## Projects

### Iris Multi-Class Classification Pipeline
**Code:** [Task1_Iris_Classification](https://github.com/thiloshanaravichandran6-ai/Datheon_Machine_Learning_-_Data_Science_Internship/tree/main/Task1_Iris_Classification)
**Goal:** Predict iris flower species and compare two classification models.
**Description:** Built an end-to-end pipeline: data exploration with a
pairplot, an 80/20 stratified split, feature scaling fitted on the
training data only to avoid data leakage, and training of Logistic
Regression and Decision Tree models. Evaluated with accuracy, precision,
recall, F1-score, confusion matrices and decision boundary plots.
**Skills:** data exploration, feature scaling, model evaluation, visualization
**Technology:** Python, Pandas, Scikit-Learn, Seaborn, Matplotlib
**Results:** Logistic Regression reached 93.3% accuracy and the Decision
Tree reached 96.7%. Both separated setosa perfectly, and all errors were
between versicolor and virginica.
